# Spec Delta

## Purpose

提供基於官方空氣品質防護準則的確定性規則審核與生成後數值一致性檢核，防範模型幻覺並保障公眾健康指引之醫療安全邊界。

## ADDED Requirements

### Requirement: 確定性安全規則引擎
系統 MUST 實作符合台灣環境部「空氣品質指標 (AQI) 活動建議規範」之確定性程式邏輯，其判定結果作為安全邊界並優先於 LLM 之生成內容。

#### Scenario: 嚴重空污達到有害門檻
- **WHEN** 預測或實測 AQI 達紅色警戒（AQI > 150）或紫色危害等級
- **THEN** 系統強制附加安全停損規則，不可因提示詞誘導而建議戶外劇烈運動

### Requirement: 數值對齊與生成後審查 (Post-generation Guard)
系統 MUST 於回覆輸出前執行對齊驗證，確保回覆內出現之所有數值（AQI、PM2.5 等）與工具調用回傳之真實數值完全一致。

#### Scenario: 檢出幻覺數值
- **WHEN** LLM 回覆之數值與底層工具回傳之實際預測值不符
- **THEN** 安全攔截器觸發告警，覆寫修正數值或替換為安全確定性模板回覆
