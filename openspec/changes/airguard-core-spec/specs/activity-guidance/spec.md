# Spec Delta

## Purpose

結合預測環境指標、使用者生理敏感分級與運動代謝當量（MET），產出具體且個人化的戶外活動調整建議與時段重排指引。

## ADDED Requirements

### Requirement: 個人化活動風險綜合評估
系統 MUST 依據使用者敏感類別（如一般民眾、氣喘/呼吸道敏感、心血管病史、兒少/年長者）及活動強度等級，綜合預測 AQI 產生個人化風險警示。

#### Scenario: 敏感族群高強度戶外運動諮詢
- **WHEN** 氣喘使用者計畫在預測 AQI > 100（對敏感族群不健康）時段進行戶外慢跑
- **THEN** 系統明確發出健康預警，強烈建議調整為室內替代方案或推遲至空氣品質回升之建議時段

#### Scenario: 尋求最佳戶外運動黃金時段
- **WHEN** 使用者請求推薦當天最佳運動時段
- **THEN** 系統比對當日 1–6 小時預測序列，篩選出污染物濃度最低之連續安全窗口並提供給使用者
