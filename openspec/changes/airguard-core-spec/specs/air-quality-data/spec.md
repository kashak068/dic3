# Spec Delta

## Purpose

提供台灣環境部空氣品質監測資料的即時串接、時序前處理、資料品質檢核與高可用快取機制，為預測與代理人提供標準化環境特徵。

## ADDED Requirements

### Requirement: 即時測站資料擷取
系統 MUST 定期自環境部開放資料平台擷取指定測站（如台中西屯、忠明）之即時空氣品質指標與污染物觀測數據（PM2.5, PM10, O3, NO2, SO2, CO）及氣象要素。

#### Scenario: 成功擷取測站觀測值
- **WHEN** 系統發送排程或即時查詢請求至環境監測資料端點
- **THEN** 系統解析並返回包含各污染物數值、單位、更新時間與測站狀態的標準化資料結構

#### Scenario: 測站通訊異常或資料缺漏
- **WHEN** 目標測站之遠端 API 連線逾時或回傳空值
- **THEN** 系統 MUST 啟用降級策略，標記資料有效性狀態，並取用最近有效快取或鄰近測站輔助數據

### Requirement: 異常值檢核與時序特徵工程
系統 MUST 對觀測數據進行異常值濾除、極值截斷，並計算滑動窗口特徵（1小時、3小時變化率與歷史均值）。

#### Scenario: 觀測值超出合理物理範圍
- **WHEN** 感測器回傳負值或超出感測上限之極端異常數值
- **THEN** 系統自動標記為異常並依據前後時序數據進行平滑修補，避免污染後續模型特徵
