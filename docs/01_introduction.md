# 第一章 緒論 (Introduction)

## 1.1 研究背景 (Research Background)

隨著全球都市化與工業活動的持續擴展，環境大氣污染已成為威脅公眾健康的重大全球性公共衛生議題。世界衛生組織（World Health Organization, WHO）在《全球空氣品質指引》（Global Air Quality Guidelines）中明確指出，懸浮微粒（$\text{PM}_{10}$）、細懸浮微粒（$\text{PM}_{2.5}$）以及對流層臭氧（$\text{O}_3$）等空氣污染物，與心血管疾病、慢性阻塞性肺病（COPD）、氣喘急性發作以及早逝率具有顯著的正相關性。

在現代健康生活型態的提倡下，戶外體育鍛鍊（如慢跑、騎乘自行車、高強度間歇訓練）以及學童與年長者的戶外日常作息被廣泛鼓勵。然而，人體在進行中高強度體能活動時，換氣量（Minute Ventilation）可提升至靜止狀態的數倍至十數倍以上，呼吸模式亦從鼻腔過濾轉為口腔換氣，導致單位時間內沉積於人體下呼吸道與肺泡微血管屏障的污染物劑量呈倍數劇增。尤其在具有特定地形與氣象條件的盆地或背風地區（例如台灣中部台中盆地，秋冬季節易受中央山脈阻擋導致擴散條件極度不良，伴隨逆溫層壓制形成局部高濃度污染累積），大氣污染常展現出極高的非線性時空突發性。因此，如何在維持戶外活動生理效益的同時，精確規避短期極端暴露風險，成為當代預防醫學與環境資訊科學迫切需要解決的交叉課題。

## 1.2 問題陳述 (Problem Statement)

儘管當前各國環境監測機構（如台灣環境部 MOENV）已廣泛佈建高精度自動空氣品質監測站，並透過即時看板與行動應用程式發布空氣品質指標（Air Quality Index, AQI），但現行的環境健康防護體系在實際個人決策支援層面仍面臨以下三大根本癥結：

1. **時間維度上的「觀測滯後性」而非「決策前瞻性」**：
   現有官方系統發布之 AQI 與各污染物濃度，本質上為「過去一小時或即時之歷史觀測值」。然而，公眾規劃戶外活動（例如排定下午進行長距離跑步或學校排定室外體育課程）往往需要的是「未來 1 至 6 小時」的暴露預期。當民眾出門時若僅參考當前良好指標，一旦遭遇午後光化反應導致的臭氧飆升或傍晚擴散停滯引發的細懸浮微粒驟升，即陷入被動暴露的高風險情境。
2. **評估維度上的「齊頭式廣播」而非「個人化情境計算」**：
   傳統 AQI 警示多採用廣播式顏色級距與籠統的健康指引（如「敏感族群應減少體力消耗」）。這種齊頭式建議忽視了個體在「生理易感性」（如健康成年人、氣喘兒少、年長心血管病患）與「活動代謝當量」（Metabolic Equivalent of Task, MET，例如靜態散步約 2.5 METs，而戶外高強度跑步可達 8–10 METs 以上）的巨大差異，無法為特定個體計算動態暴露劑量並給出具體可執行的調整方案（如最佳替換時段、建議活動時長上限或安全強度折衷）。
3. **資訊互動上的「工具割裂」與「生成式 AI 的可信度缺陷」**：
   隨著大型語言模型（LLMs）的普及，使用者日益傾向以自然語言尋求健康作息諮詢。然而，未經工具綁定的通用語言模型本質上為機率文字生成器，缺乏動態獲取即時環境監測數據的能力，經常憑空臆造數值或曲解官方安全標準（即「醫療與數值幻覺」）。若將未具安全邊界的對話模型直接用於公眾健康指引，極易產出危及生命的錯誤安全承諾。

## 1.3 研究動機 (Research Motivation)

本研究的根本動機，在於推動環境健康資訊服務從傳統的「靜態、被動、通用型數據監測（Passive Monitoring）」典範，跨越至「動態、主動、前瞻預測驅動且嚴格對齊安全規範的個人化決策支援（Forecast-Driven, Actionable Decision Support）」。

具體而言，我們觀察到結合現代「輕量化時間序列機器學習預測」與「具備工具調度能力之大型語言模型代理人（Tool-Orchestrated LLM Agent）」具備極大的互補優勢：
* 時間序列回歸模型能夠以毫秒級的延遲，依據當前氣象變化與歷史污染趨勢，推論未來 1 至 6 小時的局部濃度演變；
* 確定性規則引擎能夠忠實落實環境部官方醫療防護邊界，充當絕對不可踰越的「硬護欄（Hard Guardrails）」；
* LLM 代理人則扮演同理心與多輪交互的溝通界面，透過嚴格的 Function Calling（結構化工具調用）解析使用者意圖、抽取個體特徵、調用上述底層引擎，並轉化為具備溫度的生活化具體行動指南。

## 1.4 研究缺口 (Research Gaps)

綜合文獻與現行技術系統，本研究識別出以下關鍵研究缺口（Research Gaps）：

* **Gap 1: 短期時序預測與對話式代理人即時調度的延遲斷層**
  傳統環境科學傾向於建立龐大、高延遲的物理化學數值模型（如 WRF-Chem）或深層巨型深度神經網路，其單次推論耗時動輒數分鐘以上，無法嵌入要求次秒級反應的互動式對話循環（Conversational Loop）。學界亟需一種推論延遲低於 200ms、且能精準捕捉 1–6 小時轉折峰值的特徵工程與回歸預報整合方案。
* **Gap 2: 醫療健康安全規範在自然語言生成中的「軟性對齊」不可靠性**
  現有大多數對話系統嘗試僅依賴提示詞工程（Prompt Engineering）或純 LLM 意圖判斷來遵循健康指引，但在對抗性提示或罕見極端天氣場景下容易發生語義漂移或數值對齊崩潰。目前缺乏一種將「確定性規則引擎」與「生成後數值一致性檢驗器（Post-generation Verification）」無縫嵌入 Agent 推理鏈的架構驗證研究。
* **Gap 3: 結合生理敏感性與活動代謝強度的綜合暴露決策模型匱乏**
  現有環境應用多停留在「展示 AQI 數值」，鮮少將「運動強度（METs）」與「生理脆弱度分類（Asthma/COPD/Pediatric/Geriatric）」進行量化融合，無法針對「在何時換成室內運動」或「推遲到幾點即可安全慢跑」等具體行動決策提供閉環建議。

## 1.5 研究目標 (Research Objectives)

為填補上述缺口，本研究提出 **AirGuard AI** 系統，核心研究目標具體包含：

1. **構建高可用即時環境特徵與資料工程管線**：
   整合台灣環境部（MOENV）開放資料 API，建立具備滑動時序窗口、空間測站映射與物理異常值修復的特徵管道。
2. **研發短程 1–6 小時污染物濃度多步前瞻預測引擎**：
   以 2024–2026 年台中市大氣監測測站為實證標的，研製低延遲、高靈敏度的輕量級時序回歸預測模型（LightGBM 基準架構），並量化輸出預測不確定性區間。
3. **設計基於 Function Calling 的 Tool-Orchestrated 決策代理人**：
   運用 LangChain/LangGraph 框架與 Pydantic 契約協議，設計具備主動追問、狀態管理與工具自主編排的 AI Agent。
4. **建立具備雙層硬護欄（Dual-Layer Guardrails）的確定性安全評估機制**：
   程式化編碼官方 AQI 活動健康防護規範，並研發回覆前數值對齊攔截器，確保 AI 建議對醫療規範之依從率達 100%、數值幻覺率降至 0%。
5. **建立嚴謹的滾動回測評估與 30 組端到端情境基準測試集（Benchmark）**：
   對回歸模型進行 Walk-Forward 滾動回測，並針對 5 類典型受眾與 6 類極端大氣狀態構建 30 組全覆蓋場景測試集，全面驗證預測誤差、系統延遲與安全防護成效。

## 1.6 提出方法概述 (Proposed Approach)

AirGuard AI 採用模組化、解耦的微服務體系架構，整體分為三大層級：

```
                      [ 使用者自然語言輸入 ]
                                │
                                ▼
┌─────────────────────────────────────────────────────────────┐
│ 1. 互動與對話代理層 (Agentic Interaction Layer)            │
│    - FastAPI 異步路由 & WebSocket 通訊                      │
│    - LLM (ReAct 思考鏈 + Pydantic Function Calling)         │
│    - 會話狀態與意圖解析 (抽取地點、時間、活動類型、敏感群體) │
└──────────────┬──────────────────────────────▲───────────────┘
               │ 結構化工具調用                │ 觀測/預測/規則結果
               ▼                              │
┌─────────────────────────────────────────────┴───────────────┐
│ 2. 確定性服務與預測引擎層 (Deterministic Services Layer)    │
│    - 數據服務: MOENV API 串接、異常清洗、時序滑動特徵快取   │
│    - 預測引擎: 1–6 小時 LightGBM 多步回歸 + 信心區間計算     │
│    - 規則引擎: 台灣環境部官方 AQI 活動防護規範對照矩陣      │
└─────────────────────────────────────────────┬───────────────┘
                                              │ 生成初步回覆
                                              ▼
┌─────────────────────────────────────────────────────────────┐
│ 3. 雙層安全驗證攔截層 (Safety & Guardrail Layer)            │
│    - 數值對齊校驗器: 檢查生成文本與工具回傳數據之一致性     │
│    - 臨床安全熔斷器: 嚴重污染時強制覆蓋為官方安全模板       │
└─────────────────────────────────────────────┬───────────────┘
                                              │ 安全回覆
                                              ▼
                       [ 使用者行動決策回饋 ]
```

## 1.7 研究貢獻 (Research Contributions)

本研究的預期學術與實務貢獻可歸納為以下五大維度：

1. **範式轉移貢獻（Paradigm Shift）**：
   成功實證了環境健康資訊服務從「被動觀測回報」走向「短程預報驅動 + 個人化決策建議」的技術可行性，建立了跨越環境工程、人工智慧與預防醫學的交叉系統範式。
2. **工具調度架構貢獻（Architectural Contribution）**：
   提出了嚴格解耦的 Tool-Orchestrated Agent 架構，驗證了透過 Pydantic Schema 拘束下的 Function Calling 能徹底解決語言模型在專業環境數值領域的「知識時效性」與「虛構幻覺」難題。
3. **混合安全防護貢獻（Safety Alignment Contribution）**：
   提出了「確定性官方規則引擎 + 生成後數值比對攔截」的雙層護欄機制，相較於傳統純提示詞對齊，在醫療與公共衛生等高風險諮詢領域提供了可證明的安全邊界。
4. **低延遲短期時序預測貢獻（Forecasting Contribution）**：
   針對台中市 2024–2026 年監測資料，驗證了輕量級機器學習模型結合滑動滯後特徵在 1–6 小時突發污染預報上的精確度與即時性（推論延遲 < 200ms），滿足了互動式對話代理人對即時性的嚴苛要求。
5. **公開可重現之基準測試貢獻（Benchmark & Open Science Contribution）**：
   全面遵循 Spec-Driven Development（OpenSpec）規範，並將釋出涵蓋 5 類受眾與 6 種污染場景之 30 組端到端對話評測資料集與評估標準，為後續環境 AI 代理人研究提供客觀基線。
